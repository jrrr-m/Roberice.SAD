================================================================================
ROBERICE POS & INVENTORY MANAGEMENT SYSTEM
XAMPP DATABASE SETUP & INSTALLATION GUIDE
================================================================================

PROJECT NAME: Roberice POS & Inventory System
DATABASE NAME: roberice_db
WEB ROUTE: http://localhost/Roberice.SAD/database/init_db.php
SQL DUMP FILE: database/roberice_db.sql
CONFIGURATION: api/db.php

--------------------------------------------------------------------------------
OPTION A: AUTOMATIC SETUP (FASTEST - RECOMMENDED)
--------------------------------------------------------------------------------
1. Start XAMPP Control Panel -> Click Start on "Apache" and "MySQL".
2. Open your web browser and navigate to:

   http://localhost/Roberice.SAD/database/init_db.php
   (Or replace "Roberice.SAD" with your local project folder name)

   This script will automatically:
   - Create the `roberice_db` database with utf8mb4 collation
   - Generate all 8 tables (users, product, inventory, inventory_batch, 
     inventory_adjustment, sales_transaction, transaction_item, file_records)
   - Seed all default admin & cashier accounts
   - Once created, it immediately and automatically loads the login page!

3. You will be automatically redirected to:
   http://localhost/Roberice.SAD/pages/login.html

--------------------------------------------------------------------------------
OPTION B: MANUAL PHPMYADMIN IMPORT
--------------------------------------------------------------------------------
1. Start XAMPP Control Panel -> Click Start on Apache and MySQL.
2. Open Browser -> Go to http://localhost/phpmyadmin
   - Click "New", enter database name: roberice_db (Collation: utf8mb4_general_ci), click "Create".
   - Click "Import", choose file "database/roberice_db.sql", and click "Import".
3. Open http://localhost/Roberice.SAD/pages/login.html
